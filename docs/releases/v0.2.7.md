# 雁信 0.2.7（Alpha）

0.2.7 统一收口归档组、存档校验、原格式打印和本地加密凭据库。

## 归档组与导入

- 归档组内文件夹支持重命名和永久删除；删除只清除本地邮件与存档文件，并有二次确认。
- 导入成功即写入存档健康缓存，首次快速校验可直接命中。
- 导入对话框显示本次写入位置（内置/外置）、外置目录及可用状态；外置不可用时明确提示。
- 快速/深度校验增加「已检查 X / Y」进度和取消；取消不会写回本次缓存。

## 打印

- 打印正文使用 Shadow DOM 隔离，保留邮件原有样式、字体、表格、body class 和模板结构。
- 打印前有界等待图片、样式和字体加载，最多 15 秒。
- macOS 使用独立 A4 纵向打印参数：100% 缩放、16mm 页边距，系统打印面板可调整纸张、方向和缩放。

## 本地加密凭据库

- 凭据改存 AES-256-GCM `credentials.vault`，主密钥由 `/usr/bin/security` 读写，避免自签名应用重建后反复钥匙串授权。
- 保留旧 Keychain 条目；升级后可在「设置 → 邮箱账号 → 迁移凭据」显式迁移，失败项提示重新连接。
- 账号删除改为凭据墓碑，数据库删除失败可恢复。
- 安全取舍：同一登录用户下的其他程序在知道路径时可解密凭据库；这是换取免重复授权的代价。

## 升级说明

- 首次使用新凭据库需要执行一次「迁移凭据」，可能需要一次系统钥匙串授权。
- 旧 Keychain 条目不会删除；如需回退旧版，仍可使用。
- 迁移前建议备份 `mail.sqlite3`；`credentials.vault` 不包含在邮件备份中，可单独备份应用数据目录下的该文件。
- 最低系统版本 macOS 13。
