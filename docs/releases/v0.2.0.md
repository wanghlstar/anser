# 雁信 0.2.0

Alpha 预发布版：不会通过应用内更新自动推送给 0.1.9 用户，需要手动下载安装。

## 阅读窗与写信窗改成真正的系统窗口

- 双击列表或在右键菜单里选「在新窗口打开」，打开的是一扇真正的独立窗口：可以拖到主窗口之外、拖到屏幕边缘、盖在别的应用上面，不再被主窗口框住。
- 每扇窗口有自己的标题栏、红黄绿三灯和独立的最小化/最大化；⌘W 只关当前这一扇，主窗口的 ⌘W（收进托盘）不受影响。
- 同一封邮件只开一扇窗，重复打开会回到已经开着的那扇。阅读窗里的回复、全部回复、转发、导出原始邮件、保存附件、打开邮件里的链接，都仍由主窗口处理，行为和以前一致。
- 写信窗标题显示草稿主题；点红灯或按 ⌘W 时，有内容会先问「取消 / 不保存 / 保存」，空白草稿直接关掉。
- 窗口里的拖动、缩放、最大化都交给系统，因此天然只作用于当前这扇窗。

## 窗口不在前台时的入口

- 写信窗被别的应用挡住或最小化后，主窗口下方会浮出「继续写信」条，点一下就把写信窗拉回最前面；回到前台后浮条自动消失，草稿新标题也会实时跟新。
- 阅读窗同样：不在前台时主窗口下方浮出「查看邮件」条（显示邮件主题），点击即回到前台。
- 同时有多扇窗口不在前台时，浮条依次向上错开，不会叠在一起。

## 记住窗口，也记住「铺满」

- 以前把主窗口拖到屏幕顶部填充（或最大化）后重启，窗口会比上次小一圈、两侧留缝；现在会按当前屏幕的可用区域重新铺满——改过 Dock 大小或位置、换过显示器分辨率之后也一样。
- 手动调出来的自定义大小和位置照旧记住，不会被强制铺满。

## 收取与列表

- 列表右上角的刷新改成按钮组：默认收取全部账号，也可以只收指定的某一个账号；托盘菜单仍然是收全部。
- 最窄宽度下列表标题不再被截断。

## 修复

- 修掉两个窗口里部分按钮和拖拽附件偶发失灵：应用的权限清单没有把新窗口类型列全，原生窗口里的部分调用被系统拒绝。
- 修掉写信窗与阅读窗之间的事件串门，之前可能造成界面卡死。

## 安装

- 这一版是 Alpha：应用内更新不会自动推给你，也不会覆盖稳定版通道。请下载 DMG 手动安装，账号、本地存档与设置都会保留。
