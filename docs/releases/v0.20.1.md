# 雁信 0.20.1（本地检查点）

本版本是本地装机用的检查点，**不发布、不推 tag 到 origin**，也不进入 Alpha 预发布通道。

## 过滤规则

- 条件新增：以此开头 / 以此结尾、邮件大小（KB）、邮件日期、已读状态、星标状态、抄送、收件人或抄送、优先级、已接收天数。
- 首次匹配时记录已读/星标状态，同一条规则的连续动作与后续规则都按原始状态判断，不会被「标记为已读」等动作打断。
- 预览会区分「实际匹配」与「等待完整邮件核对」；旧存档缺少抄送/优先级头时会显示等待，待后续解析迁移补齐。
- 日期条件改用日历弹层，不再使用系统原生日期输入。

## 界面

- 设置页改为五个分类：邮箱账号 / 本地存档 / 应用偏好 / 后台任务 / 关于雁信，窄窗口自动切换为顶部导航。
- 后台任务改为五张独立卡（最近活动、完整保存任务、服务器状态同步、目录来源检查、服务器文件夹操作），默认折叠、每卡刷新。
- 规则页账号分组、服务器规则执行记录、邮件签名、全部收件箱统一为「点标题或说明整块展开/收起」的折叠头；右侧操作区左对齐。
- 规则页内容区加宽，账号分组卡头上下居中，执行记录卡头收紧。
- 「全部收件箱」勾选改为横向三列，收件箱必选且不可取消；账号配置的「服务器与高级配置」每次打开默认折叠。

## 已知限制

- 升级前已存档的邮件没有抄送/优先级头，相关规则条件会等待完整邮件核对；升级后新收到的邮件立即生效。旧存档头块回填属于后续的解析迁移批次。
- 服务器规则顺序动作引擎（一条规则最多 8 个动作、崩溃续跑）尚未移植。
