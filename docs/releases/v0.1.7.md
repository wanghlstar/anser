# 雁信 0.1.7

## 过滤规则：合并为一个「移动到文件夹」

- 规则动作合并为单一的「移动到文件夹」：
  - IMAP 账号 → 真正的服务器移动（走确认 / 重试队列），来源自动取该账号的收件箱范围（设置里的收件箱范围，未配置则 INBOX）
  - POP3 / 无服务器目录的账号 → 退化为纯本地归类
- 「移动到文件夹」可与「标记已读 / 未读 / 星标」叠加：本机标记立即生效，服务器移动在后台异步执行；「移到废纸篓」与移动互斥
- 规则卡片更紧凑：条件单行省略、目标显示服务器目录中文名、目标下拉按账号树顺序
- 撤销上一版把「本地文件夹」目标错误地列成服务器文件夹的改动
- 本地存档账号组新增「草稿箱」入口（草稿只存本机）

## 邮件列表

- 左侧勾选圈改为正圆并加深；悬停新增「星标」「标记未读 / 标记已读」快捷动作

## 设置页

- 顶部「系统通知 / 后台检查」同排等高；下方「外观 + 活动与诊断」与「存档校验」
- 「活动与诊断」合并最近活动、最近归档记录与服务器诊断，内层无边框、平铺，与「存档校验」底对齐
- 卡片改名：系统通知、存档校验、Dock 图标；开机自启移入后台检查；「校验本地原件及附件的完整性」并入存档说明

## 托盘

- 菜单栏未读计数刷新更快（1 秒轮询）
- 托盘「免打扰」与设置页「新邮件通知」双向同步

## 本地存档（Fork 增强）

- **移动邮件后本地存档同步搬迁**：在服务器上把邮件移到其他文件夹后，本地 `.eml` 文件会一并搬到新文件夹名下——磁盘布局、侧边栏存档树、服务器文件夹三方保持一致。搬迁在数据库提交之后执行，失败仅记录日志、不影响读取；目标已存在同内容文件时自动去重。
- 来信仍是“先完整落盘、后归集”：规则执行前邮件已是持久的本地原件。

详见本地开发文档。
