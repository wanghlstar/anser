# 雁信 0.1.8

## 邮件列表右键菜单重构

- 迁移到 shadcn `ContextMenu`：靠近屏幕边缘自动翻转，支持方向键导航、Esc 关闭，焦点与层级由 Portal 统一（不再自绘浮层）。
- 按当前列表上下文显示动作：
  - 收件箱 / 未读 / 星标 / 本地存档：回复、回复全部、转发、星标、已读、移动到文件夹、完整保存到本地、移到本地废纸篓
  - 已发送 / 自己发出的邮件：重新编辑、转发、移动到文件夹、移到本地废纸篓
  - 本地废纸篓：从废纸篓恢复、彻底删除（含服务器）
- 「星标」「已读」改为状态切换（勾选框），不再并列两个互斥项；危险动作单独分组。
- 多选时批量项作用于选中集；回复 / 转发 / 重新编辑作用于右键的那一封。

## 「移动到文件夹」统一为跟随账号

- 右键菜单、顶部批量工具栏、阅读器工具栏三处统一为同一套「移动到文件夹」。
- 目标跟随选中账号，顺序与账号树一致（角色 + 中文拼音）：
  - IMAP 账号 → 该账号的服务器文件夹
  - POP3 / 无服务器目录账号 → 本机归档现有目录
- 落地语义：
  - 服务器上仍存在 → 真正的 IMAP 移动（执行前二次确认，所有设备可见；本机存档会随新来源自动归位）
  - 服务器已删、仅本机存档 → 只把本机归档从原目录重定到目标目录（可逆，不触发任何服务器操作）
- 批量工具栏按上下文收窄：收件箱保留 完整保存 / 已读 / 未读 / 移动 / 废纸篓；已发送只留 移动 / 废纸篓；废纸篓只留 恢复 / 彻底删除。
- 移除旧的「归入本地文件夹」平铺归类对话框（本地文件夹标签仍可由规则使用）。

## 本机归档重定（新增）

- 服务器已删 / 非 IMAP 的邮件可单独调整本机归档目录（`move_local_archive`）：只改归档来源行，不动服务器；本地存档树与列表随之从 A 迁到 B。
