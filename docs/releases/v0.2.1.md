# 雁信 0.2.1（Alpha）

0.2 主线的最新 Alpha 发布：从 0.2.0 起累积的窗口、规则、存档与设置改进。此前 0.20.x 是本地检查点，不进入发布通道。

## 写信与阅读窗口

- 写信窗或阅读窗在前台时，点 Dock、托盘、全局快捷键不再抢焦点、不最小化窗口。
- 主窗口关闭只隐藏主窗口；写信窗变成「继续写信」，恢复主窗口后悬浮条仍在。
- 写信窗自己的关闭仍走「保存 / 不保存 / 取消」。
- 「继续写信」和「查看邮件」悬浮条新增 X：写信窗可直接保存或舍弃并关闭，阅读窗可直接关闭。
- 修复 Retina 屏幕下新写信窗跑到屏幕外的问题，按逻辑坐标居中并限制在当前屏幕内。

## 规则

- 旧规则的 `read+trash`、`serverMove+read` 等组合动作会在编辑器中拆成多个步骤，不再显示为空。
- 顺序动作最多 8 个，支持本地/服务器移动、复制、已读、星标、删除与保存；带首次匹配快照和崩溃续跑。
- 规则执行记录与后台任务分开显示，服务器动作结果可追溯。

## 存档与收取

- 旧存档解析升级到 v5：只读头块回填抄送、优先级与元数据，不重新解码正文或附件。
- 本地归档会真正搬移 `.eml`，不再只改目录字段；规则和手动归档行为一致。
- 「收取邮件」支持全部账号或指定账号，`⌘R` 收取全部，回复改为 `⌘⌥R`。

## 界面与更新

- 设置页六分类导航与后台任务卡；应用偏好全宽横卡布局。
- Dock 未读角标、更新说明 Markdown、历史版本列表。
- 全局「恢复窗口快捷键」默认 `⌘⌥` + 反引号，可录制，录制时暂停当前全局键。

## 更新说明

- 本次是正常发布的 Release（标题标注 Alpha），`releases/latest` 会指向它，支持应用内更新。
- 从 0.2.0 可直接应用内更新。
- 从本地 0.20.x 检查点升级：0.2.1 的 semver 更小，应用内更新不会自动降级；请手动安装一次 DMG，之后 0.2.x 可正常自动更新。
