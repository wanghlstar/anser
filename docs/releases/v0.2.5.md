# 雁信 0.2.5（Alpha）

0.2.5 加入账号分段、独立存档、EML/mbox 导入导出与存档诊断，完善本地存档迁移和导入后的规则归类。

## 账号分段与独立存档

- 支持把旧账号冻结为只读分段，再添加同地址的新分段继续收信；分段可设置收信起点，避免重复收取旧邮件。
- 冻结分段停止收信、发送和服务器规则动作，仍可阅读、搜索、导出、导入和补存。
- 账号菜单新增「新建同地址分段」「冻结为只读」「恢复为可写」；新建分段时可顺手重命名原分段。
- 存档布局升级为 `archive/<邮箱>__<账号短ID>/<文件夹>/<hash>.eml`，同一邮箱的多个分段各自独立目录。
- 旧存档布局会自动迁移；外置盘未连接时记录待迁移，接回后下次启动继续。

## 邮件导入导出

- 支持选中邮件或全库导出 EML，按账号和文件夹建立目录；全库导出可选择「平铺」，全部放入同一目录。
- 支持导入 EML 和 mbox（mboxrd），可导入到「本地导入」或已有本地文件夹；按账号和邮件内容去重。
- 导入只写入本地存档，不会上传、复制或移动服务器邮件；导入在后台继续，关闭对话框不会中断。
- 导入完成显示新增、跳过和失败数量，失败明细可复制；重复导出到同一目录不会重复生成副本。
- 导入后的邮件可用过滤规则归入目标文件夹，不会产生服务器操作。

## 存档诊断与修复

- 设置页新增「诊断与支持」，账号菜单新增「诊断此账号」。
- 只读检查数据库完整性、搜索索引、存档布局、外置盘连接、原件缺失、待迁移记录和后台任务。
- 诊断报告可复制，邮箱地址自动脱敏。
- 提供安全修复入口：重试存档迁移、规范存档目录、重建搜索索引。

## 界面与操作

- 导入、导出入口集中到本地存档卡片；导入支持目标文件夹选择。
- 账号卡改为紧凑两行布局，新账号和新分段置顶。
- 服务器与高级配置默认折叠，自动填写失败时才展开。
- 分段创建、冻结状态和存档健康状态在账号卡与存档页统一展示。

## 升级说明

- 首次启动会迁移旧存档布局；邮件较多时需要一些时间，迁移先复制校验再更新路径，不删除未完成迁移的原件。
- 如果外置存档盘未连接，相关邮件会暂时显示为不可读；接回外置盘后重启雁信即可继续迁移。
- 建议升级前保留现有存档备份；本次升级不修改邮件正文和附件内容。
- 0.2.4 用户可在发布后通过应用内更新升级。
- 本机自签名证书没有稳定的 Team ID；升级或重新构建后首次读取钥匙串可能要求一次系统授权，允许后本版本正常使用。
- 最低系统版本仍为 macOS 13。
