# 雁信 0.20.2（本地检查点）

本版本是本地装机与后续上游同步的检查点，**不发布、不推送 tag 到 origin**，也不进入 Alpha 预发布通道。

## 规则与存档

- 旧存档解析迁移：`PARSER_VERSION` 升到 5；已有原件的旧邮件只读头块回填抄送、优先级与元数据已知标记，不重新解码正文或附件。
- 规则预览可区分「实际匹配」与「等待完整邮件核对」；旧邮件补齐头块后，抄送、优先级、大小、正文条件不再被误判为空。
- 顺序动作引擎：一条规则最多 8 个动作，持久化游标、首次匹配快照与崩溃续跑；支持归档、标记、星标、删除、服务器复制/移动等动作。
- 后台任务新增「规则处理任务」，与服务器规则执行记录并存，不覆盖原有动态来源与执行结果。

## 更新与窗口

- 更新中心支持 Markdown 更新说明与安全消毒，并拉取当前版本到目标版本之间的全部 Release 历史。
- 新增全局「恢复窗口快捷键」，默认 `⌘⌥` + 反引号；可在应用偏好直接录制，录制时暂停当前全局键，保存失败回滚旧键。
- macOS 15 下恢复窗口后改用 LaunchServices 无条件重开当前 bundle，解决窗口已恢复但前台仍停留在其他 App 的问题。

## 界面与偏好

- 应用偏好改为全宽横卡布局，快捷键与开关同行，间隔与外观选项分摊宽度。
- macOS Dock 显示未读角标，零未读时清除；口径与托盘、全部收件箱一致。
- 规则页与设置页统一折叠头、间距和宽度；设置页保持六分类导航。

## 验证

- 前端 54 文件 / 449 例、Rust 373 passed / 2 ignored。
- `tsc`、Prettier、UI 铁律检查、桌面脚本 18 项与生产构建通过。
- 已安装 `/Applications/雁信.app`，实测默认快捷键录制、最小化恢复与前台激活。

## 已知限制

- 上游 0.1.22/0.1.23 的中英文界面、0.1.17/0.1.18 的双语翻译与全局代理尚未移植。
- 「全部邮件」未读口径仍待产品决策；当前沿用统一收件箱与每账号可配置范围。
- 本地 tag 仅作检查点，不推送到 `origin`。
