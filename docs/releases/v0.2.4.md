# 雁信 0.2.4（Alpha）

0.2.4 增加会议邮件识别与日历联动，完善本地存档校验和收件箱计数，修正移动邮件留下多条来源记录的问题，并调整设置页布局。

## 会议邮件

- 自动识别纯文本的企业微信会议、腾讯会议邮件，提取会议时间、会议号和入会链接。
- 阅读页顶部显示会议卡片，可直接加入会议、复制会议号或添加到日历；可忽略提醒，之后从日历恢复。
- 已安装会议 App 时优先激活已运行实例，避免重复打开；未安装时回退浏览器打开入会链接。
- 日历中的会议日程支持「加入会议」和「复制会议号」；复制后可直接打开会议 App。
- 从会议邮件创建的日程保留会议号、入会链接、发件人和邮件时间，默认提前 15 分钟提醒。

## 本地存档

- 每天 10:00 和 17:00 自动校验本地存档；发现问题时写入活动日志并发送通知。
- 「本地存档」页保留上次校验结果，重启后仍显示；重新校验时保留旧结果并提示上次校验时间。
- 设置外置存档后新增「打开存档」按钮，直接在 Finder 打开外置存档目录；未设置时不显示。
- 按钮顺序调整为：打开存档 / 立即归档 / 取回本地 / 校验存档 / 规范目录。
- 邮件移动后只保留目标目录一条来源；启动和同步后自动归位历史来源，修复收件箱被旧 INBOX 记录重复计数的问题。
- 服务器已删除、仅本地存档的邮件按归档目录计一次，避免服务器重扫后收件箱数量虚高。

## 界面与日历

- 侧栏「邮件」标题改为「邮件导航」。
- 微调侧栏间距与底部导航。
- Apple 日历默认保持折叠。
- 修复在邮件列表右键时误触第一项的问题。
- 「恢复窗口快捷键」移到「应用偏好 → 间隔与外观」。

## 数据修复

- 首次启动 0.2.4 会自动执行一次来源归位和存档路径整理，把历史移动邮件收敛为单条来源；日志会显示「来源归位 N 封」「存档路径已修复/整理 N 封」。
- 本次升级不删除本地邮件正文或附件；如外置存档未挂载，归位会跳过，接上外置盘后下次启动会重试。

## 更新说明

- 0.2.3 用户可直接应用内更新。
- 最低系统版本仍为 macOS 13。
- 会议 App 打开方式依赖本机已安装的企业微信/腾讯会议；未安装时使用浏览器打开入会链接。
