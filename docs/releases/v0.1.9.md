# 雁信 0.1.9

## 写信窗口改成 Foxmail 式浮动面板

- 写信不再是盖住主界面的模态框：标题栏可拖动，四边与四角可缩放，双击标题栏或点绿灯最大化，黄灯最小化，红灯关闭。
- 与主界面互不阻塞：写信窗口开着也能正常浏览、搜索、阅读、多选邮件。
- 三灯换成 macOS 风格（关闭 ×、最小化 —、最大化/还原 ⤢）；最小化后点「继续写信」保持原来的最大化状态。
- 点写信窗口之外的地方自动收成窗口底部的「继续写信」细条，不再打断写信。
- 写信窗自己派生出来的浮层（正文图片的 − % + 缩放浮条、通知横幅、工具条提示气泡、另一封的「继续写信」细条）不会再把窗口收起来。
- 修掉「一按标题栏窗口就漂移半个身位」和「标题栏拖不动」：居中不再依赖 `translate`，改用 `left/right + margin:auto`，并关掉入场缩放动画对测量的干扰。

## 同时写多封信

- 可以同时打开多封写信窗口，各自的正文、附件、收件人、窗口位置与最大化/最小化状态互不影响。
- 写第一封时最小化，再临时写第二封或回复收件箱里的邮件，不再覆盖第一封。
- 多封最小化后的「继续写信」细条依次向上错开，不会叠在一起。

## 富文本写信

- 默认富文本正文，可切到 Markdown 源码；问候语、签名、全角空格首行缩进照旧。
- 工具条压成一行，密送可展开收起，收件人区更紧凑。

## 附件

- 写信附件条：可多选添加、可拖拽添加，也可在 Finder 里 ⌘C 复制文件后到写信窗口 ⌘V 直接粘贴为附件。
- 草稿使用自有附件副本，正文图片也随草稿管理，草稿与发送不依赖原邮件是否还在。
- 转发时自动带上原邮件的附件（精简移植上游 0.1.11）。
- 纸张夹、回形针等图标与邮件列表的附件标记沿用现有样式。

## 正文图片与阅读器

- 正文图片点选后可点浮条上的 − % + 缩放（参考 Foxmail），浮条可点击、拖动窗口时不受影响。
- 阅读器图片：自定义右键菜单、复制、保存；修复原生剪贴板相关的问题。
- 正文图片加载失败给出超时提示并可重试（移植上游 0.1.14 / 0.1.19 的相关加固）。

## 列表、通知与打印

- 通知横幅可点击，直接定位到对应邮件；定位不再重复弹窗。
- 收件箱里自己发给自己的邮件不再显示「重新编辑」。
- 单封邮件打印（移植上游 0.1.13），打印面板中文化。
- 阅读快捷键与右键菜单快捷键提示（移植上游 0.1.11）。

## 存档与清理

- 本地存档不再包含已发送副本。
- 待确认删除的标记按当前视图作用域清理，废纸篓不再闪回。
- 废纸篓与彻底删除按当前文件夹独立，不再牵连同 Message-ID 的其他副本。
- 新增清空草稿箱、清空本地废纸篓；发送记录支持清空与单条删除。
- 转发附件准备期间明确提示暂时不能发送，避免误以为发送失败。
