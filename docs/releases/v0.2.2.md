# 雁信 0.2.2（Alpha）

0.2.2 汇总上游 0.1.24 的收取加固与本轮写信体验收尾，继续作为正常 Alpha Release 发布，支持应用内更新。

## 实时收取

- 收件箱改由单条 IMAP IDLE 监听连接独占：推送下载、连接后补查、每分钟只读复核和定时补查在同一会话完成。
- 后台全目录收取跳过被监听的 INBOX，避免两条连接争抢同一邮箱状态。
- 复核失败时丢弃旧会话并重连，不再复用可能已失效的连接。

## Gmail / OAuth

- 后台刷新令牌成功、但系统钥匙串写入被拒时，不再把整次收取判为失败。
- 新令牌继续在内存中使用并标记待写；用户主动检查邮件、连接账号或保存设置时再交互式写入，并提示选择“始终允许”。
- 首次写入失败只记录一次活动日志，分钟级重试不会重复弹授权。
- 修复安装后后台读取被禁止交互、账号提示“无法读取钥匙串凭据”的问题；读取失败会回退一次交互授权，选择“始终允许”后恢复正常。

## 写信与回复

- 收件人、抄送、密送输入行铺满整行；按实际宽度显示收件人，放不下才折叠为 `+N`，点击后展开全部。聚焦输入框不再自动撑开多行，“密送”入口保持靠右。
- 富文本接入 Tiptap 表格：从网页或 Excel 粘贴的表格保留行列、合并单元格和统一边框，并随草稿与发送 HTML 保存。
- 富文本新增字体颜色：灰、红、橙、绿、蓝、紫、粉 7 个预设与默认颜色；按选区应用，图标跟随当前颜色，保存前将 `rgb()` 归一化为十六进制。
- 修复空正文首行光标落到第二行的问题。
- 回复/转发主题前缀使用中文「回复：」「转发：」，发送时仍兼容剥离旧 `Re:` / `Fwd:`。
- 收信纯文本行高与邮件 HTML 段间距收紧；写信正文、签名预览与收信阅读保持一致。

## 发布与维护

- 发布流水线新增包内许可证校验：`LICENSE`、`NOTICE`、`LICENSING.md`、`licenses/shadcn-ui-MIT.txt` 缺失或为空时，在发布前中止。
- 中英文界面、邮件正文双语翻译、全局代理与邮件图片/样式仍暂缓，本版不包含。
