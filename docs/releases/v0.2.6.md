# 雁信 0.2.6（Alpha）

0.2.6 收口删除语义，补齐本地归档组、导入作业、外置导入与存档快速校验，并同步上游 0.1.27–0.1.33 的导入、地址菜单、打印、主题与代发发件人能力。

## 删除与规则

- 在线邮件「移到已删除」改为排队服务器 `MOVE` 到账号废纸篓；离线/本地邮件进入本地已删除。
- 服务器废纸篓恢复会排队移动回原文件夹；取不到原目录时回 INBOX。
- 账号废纸篓清空同时处理服务器 `UID EXPUNGE` 和本地副本，确认框分别显示服务器/本地数量。
- 移除全局「已删除」入口，删除视图跟随账号；清空按钮改为图标。
- 过滤规则支持「移到已删除」并在在线时走服务器废纸篓；支持指定废纸篓目录；「彻底删除（含服务器副本）」必须二次确认且只能作为最后一步。
- 规则各步骤只处理当前收件箱仍有活动服务器来源的邮件，避免对已归档邮件重复命中。

## 导入与本地归档组

- 新增持久化导入作业：EML/EMLX/MSG/MBOX 后台导入、逐项进度、取消、最近导入状态；每批最多 1000 封、合计 1 GiB、单封 64 MiB。
- 支持导入目录，保留相对路径，可作为 Foxmail 导出目录的导入入口。
- 新增本地归档组（右键「本地存档」新建），组内可建空文件夹；归档组不进入账号，不参与同步和规则。
- 归档组支持重命名和删除；删除只清除本地邮件与存档，服务器不受影响。
- 本地文件夹删除改为永久清除本地记录和存档文件，服务器副本不动。
- 新增「新邮件导入位置」：内置/外置。只有设置外置目录后才能选外置；切换有确认，已有邮件不迁移，外置盘未连接时导入明确失败。
- EMLX/MSG 加入 macOS 文件关联与外部只读查看。

## 存档校验与性能

- 校验存档改为快速/深度两档。快速模式按路径、大小、mtime、hash 命中缓存直接跳过未变化文件；深度模式忽略缓存重新读取全部原件。
- 校验最多使用 8 个 worker 并行，缓存结果最后批量写回 SQLite；外置未连接只统计跳过。
- 手动校验完成发送 macOS 系统通知，并保留窗口内结果提示。

## 阅读与界面

- 地址右键新增「写邮件」「复制姓名和邮箱」，保留复制邮箱、添加/编辑联系人。
- 邮件列表右键新增「打印这封邮件」。
- 图片失败/超时记录一次诊断日志，URL 全编码。
- 主题支持跟随系统/浅色/深色；标题栏按钮快速切换浅/深，系统外观变化实时跟随。
- 解析 RFC 5322 `Sender`，阅读器、对话和打印显示「由 xxx 代发」；未知在线邮件头会在同步时补齐。
- 修复正文测量时滚动条造成的抖动、首帧主题色和列表操作菜单布局。

## 验证与升级

- Rust 457 passed / 3 ignored；前端 538 例通过；构建、界面检查与格式检查通过。
- 0.2.5 用户可通过应用内更新升级。
- 本次版本号 `0.2.6`，最低系统版本 macOS 13。
