# 雁信 0.2.9（Alpha）

0.2.9 集中完成搜索、批量文件夹操作、发送记录和大邮箱列表性能优化，不改变邮件与本地存档格式。

## 搜索

- 支持多字段、多条件搜索，按回车应用；搜索框内可直接选择字段（Foxmail 风格）。
- 多条件面板增加时间范围与最近搜索标签；时间筛选右上角可用小 `x` 直接清除。
- 搜索框铺满标题区，保存搜索与时间筛选右对齐；移除正文范围提示及覆盖扫描。

## 阅读与列表

- 已读/星标点选即时生效，先更新界面再等待后台确认；失败自动回滚本次字段。
- 未读徽标、文件夹未读数与列表移除同步更新；本地存档邮件不再被历史移动记录阻止标记。
- 新邮件到达后会话图在后台合并；合并期间保持旧列表，不再短暂显示为单封。
- 侧栏本地存档树缓存上次结果，冷启动先显示再后台刷新，读取失败不再闪空。
- 启动后静默补齐上次退出前未完成的会话合并，减少第一次切换文件夹的等待。
- 文件夹切换不再等待会话图全量重建；实测由最高约 3 秒降至 20–125 毫秒。

## 发送与后台任务

- 发送失败不再留下发送记录，并明确显示邮箱拒绝原因；移动断网自动重试。
- 发送记录并入「设置 → 后台任务」，侧栏入口移除；默认折叠，标题显示条数，清空/刷新固定在右侧。
- 后台任务与服务器任务去掉二级折叠和箭头，点标题直接展开；列表最多显示 20 条。

## 批量文件夹操作

- 同一账号复用 IMAP 会话，多选移动一次入队、批量读取服务器来源。
- 同源同目标自动合批：一条 `UID MOVE`（或 `UID COPY`）处理多封，逐封保存 COPYUID 回执并核对目标正文。
- COPYUID 支持区间解析；映射不完整的任务逐封标记结果不明，不自动重放。
- 不支持 MOVE 的服务商使用 COPY + 精确 UID 标记删除 + `UID EXPUNGE`，不使用普通 EXPUNGE/CLOSE。
- 多选已读、星标、移废纸篓在原生端合并为一次后台写入。

## 修复与维护

- 清空服务器废纸篓后同时清除残留阅读正文。
- 编辑器内 Tab 插入缩进空格；本地存档显示内置存档大小（仅设置外置时）。
- 列表计数改读后台缓存，不再在请求路径同步全量重算；会话投影改为后台重建。

## 升级说明

- 首次启动可能为会话投影做一次后台重建，期间列表保持可用；完成后自动更新分组。
- 本版本不修改邮件、附件或本地存档格式，可回退旧版。
