# 雁信 0.1.6

## 账号内草稿箱

账号文件夹树新增草稿箱入口，可直接查看该账号的草稿。右上角提供「写邮件」按钮（与顶部草稿箱一致），默认使用该账号作为发件人。

## 待发送独立面板

定时发送与队列中的邮件从发件箱分离到独立面板：

- 展示每封邮件的计划发送时间与剩余倒计时
- 支持取消发送、重新定时
- 已发送与待处理分区展示，发件箱不再混杂多种状态

## 设置页紧凑化

- 存储工具卡恢复两列底部齐平，卡片内部空间均摊到各行之间，不再出现整片空白堵在底部
- 「校验存档」与「立即归档 / 取回本地 / 规范目录」同一行
- 校验结果压缩为一行（`校验 1620 / 1620 封通过 · 最近校验：…`），仅在有问题时展开列表
- 「规范目录名」更名为「规范目录」

## 写信

问候语与签名的发送组合调整，签名内容按账号快照，切换发件身份时重新核对。

## 修复

- **开发预览启动误报没有代码签名证书**：`security find-identity` 不能带 `-v`，新版 macOS 在该模式下只输出「有效身份」段，自签证书会被过滤掉。同时解析时容忍行尾的 `CSSMERR_TP_NOT_TRUSTED` 等后缀（仅排除 `EXPIRED`/`REVOKED`），默认候选增加本机自签证书名，无需再设置环境变量。

## 已知限制

- 过滤规则一次仍只能选一个动作；多动作叠加在后继版本提供。
- 规则标记已读/星标暂不同步到服务器。
