# 日历（首版）实施计划

> **执行方式：** 本会话逐步实现，每个任务结束运行目标测试并提交。

**目标：** 在雁信内增加纯本地日历：月/周/日视图、拖拽、简单重复、提醒、邮件转日程。

**架构：** Rust 新增 `calendar` 模块与 SQLite 表，Tauri 命令暴露范围查询/保存/删除；React 新增独立 `CalendarPage`，用 `date-fns` 与自绘 CSS Grid 实现三视图；提醒复用现有通知通道。

**技术栈：** Rust / rusqlite / chrono / Tauri 2；React 19 / TypeScript / date-fns 4 / shadcn/ui。

**设计文档：** `docs/plans/2026-10-21-calendar-design.md`

---

## 任务 1：后端模型与存储

**Files:**
- Create: `src-tauri/src/calendar.rs`
- Modify: `src-tauri/src/models.rs`（如需共享类型）
- Modify: `src-tauri/src/store.rs`（建表）
- Modify: `src-tauri/src/lib.rs`（`mod calendar;`、命令、`generate_handler!`）
- Test: `src-tauri/src/calendar.rs` 内 `#[cfg(test)]`

**步骤**
1. 定义 `CalendarEvent`、`CalendarOccurrence`，camelCase 序列化。
2. 建表 `calendar_events` 与 `calendar_reminder_log`，加范围索引 `(start,end)`。
3. 实现 `list_events(from,to)`：非重复按重叠查询；重复事件展开到范围。
4. 实现 `save_event`：校验标题、时间、全天日期、颜色、提醒、重复枚举；新增/更新。
5. 实现 `delete_event(id)`：删除事件与提醒日志。
6. 单测：CRUD、全天、范围边界、重复展开、月末。

**验证：** `cargo test --manifest-path src-tauri/Cargo.toml --lib calendar`
